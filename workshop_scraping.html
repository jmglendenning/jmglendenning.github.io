Two blocks, one after each half of the lecture: rebuild your Assignment 4 scraper the polite way, then get the same kind of data from a page that hides it behind JavaScript. Work in pairs; type the code rather than paste it.

parse_books <- function(pg) {
  pods <- html_elements(pg, "article.product_pod") # 20 books
  tibble(
    title  = pods |> html_element("h3 a") |> html_attr("title"),
    price  = pods |> html_element(".price_color") |> html_text2(),
    rating = pods |> html_element(".star-rating") |> html_attr("class"),
    stock  = pods |> html_element(".availability") |> html_text2()
  )
}

stars <- c("One", "Two", "Three", "Four", "Five")
clean_books <- function(df) {
  df |> mutate(
    price    = parse_number(price), # "£51.77" -> 51.77
    rating   = match(str_remove(rating, "star-rating "), stars),
    in_stock = str_detect(stock, "In stock")
  ) |> select(-stock)
}

B2. Route 1 — find the API the page uses.

Open https://quotes.toscrape.com/scroll, then DevTools → Network → Fetch/XHR, and scroll. Each scroll calls api/quotes?page=N. Call it yourself:

library(httr2)
ua <- "EPPS6302 student; your-netid@utdallas.edu"
get_quotes <- function(page) {
  Sys.sleep(1) # one request a second
  request("https://quotes.toscrape.com/api/quotes") |>
    req_url_query(page = page) |>
    req_user_agent(ua) |>
    req_retry(max_tries = 3) |>
    req_perform() |>
    resp_body_json()
}
j <- get_quotes(1)
names(j) # has_next, page, quotes, tag, top_ten_tags
[1] "has_next"     "page"         "quotes"       "tag"          "top_ten_tags"

B3. Rectangle the JSON (R4DS ch. 23). One row per quote.

rectangle <- function(quote_list) {
  tibble(q = quote_list) |>
    unnest_wider(q) |> # author, tags, text
    hoist(author, author_name = "name", author_slug = "slug") |>
    mutate(tags = map_chr(tags,
                          \(x) paste(unlist(x), collapse = "; "))) |>
    select(text, author_name, author_slug, tags)
}

B4. Follow has_next to the end. The API tells you when to stop.

pages <- list(); p <- 1
repeat {
  pages[[p]] <- get_quotes(p)
  if (!pages[[p]]$has_next) break
  p <- p + 1
}
quotes <- map(pages, "quotes") |> list_flatten() |> rectangle()
write_csv(quotes, "data/quotes.csv")

Before you leave — write the data note

Five lines under your code, for each dataset: source and date collected; permission (robots.txt, terms, or a key); method (selector, endpoint or browser); cleaning rules applied; known gaps. This is the start of the datasheet your project proposal needs.

Tip

When it breaks. Zero elements — the selector is wrong, or the page is dynamic; run the B1 test. Â£ in prices — an encoding guess; parse_number() survives it, or read with encoding = "UTF-8". HTTP 403 or 429 — you were refused or are going too fast: stop, slow down, identify yourself; do not disguise your user agent. Chrome not found — install Chrome, then Sys.setenv(CHROMOTE_CHROME = "path"). Site unreachable — never re-run the loop; read data/books_raw.csv.
