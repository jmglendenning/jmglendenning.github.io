What you will produce

A working GovInfo API key, the ten most recent Senate Foreign Relations Committee hearings downloaded two ways, and a short report on how usable the documents are as data.

0. Apply for a GovInfo API key

  1. Sign up at https://www.govinfo.gov/api-signup with your name and UTD email. The key is issued by api.data.gov and arrives by email; one key works for GovInfo and other federal APIs.

Done

  1. Store it in .Renviron, not in your code: run usethis::edit_r_environ(), add the line GOVINFO_API_KEY=your-key, save, and restart R.

Done

  1. Test it: paste https://api.govinfo.gov/collections?api_key=YOUR-KEY into a browser. You should see a JSON list of collections.

Worked

Warning

Treat the key like the Census and YouTube keys. Never in a .qmd, never committed — your website repository is public. DEMO_KEY works in place of a key for a first test, but it is tightly rate-limited and shared with everyone else using it.

2. How to use the GovInfo API

Documentation, with a try-it-out console: https://api.govinfo.gov/docs. Every request goes to https://api.govinfo.gov and carries api_key.

  1. Collections — what exists, and what changed since a date: /collections and /collections/CHRG/2026-01-01T00:00:00Z (CHRG is Congressional Hearings; pageSize up to 1000; offsetMark=*).

  2. Search — the website’s query language, sent as JSON by POST:

library(httr2)
body <- list(
  query = 'collection:(CHRG) AND "Committee on Foreign Relations"',
  pageSize = 100,
  offsetMark = "*",
  sorts = list(list(field = "publishdate", sortOrder = "DESC"))
)
found <- request("https://api.govinfo.gov/search") |>
  req_url_query(api_key = Sys.getenv("GOVINFO_API_KEY")) |>
  req_body_json(body) |>
  req_perform() |>
  resp_body_json()

  1. Packages — one document: /packages/{packageId}/summary returns its metadata and a download list (pdfLink, txtLink, modsLink, …).

  2. Paging — each response returns the next offsetMark; send it back to get the next page. Stop when no results come back.

# Base request: every call goes to api.govinfo.gov and carries api_key
govinfo <- function(path) {
  request("https://api.govinfo.gov") |>
    req_url_path_append(path) |>
    req_url_query(api_key = api_key) |>
    req_retry(max_tries = 3)
}

B2. Search, page, and keep the first ten Senate Foreign Relations hearings

The full-text query also matches hearings of other committees that merely mention the Committee on Foreign Relations, so each candidate’s summary is checked for the committee itself.

search_page <- function(offset) {
  govinfo("search") |>
    req_body_json(list(
      query      = 'collection:(CHRG) AND "Committee on Foreign Relations"',
      pageSize   = 100,
      offsetMark = offset,
      sorts      = list(list(field = "publishdate", sortOrder = "DESC"))
    )) |>
    req_perform() |>
    resp_body_json()
}

get_summary <- function(id) {
  govinfo(paste0("packages/", id, "/summary")) |>
    req_perform() |>
    resp_body_json()
}

is_sfrc <- function(s) {
  any(map_lgl(s$committees %||% list(), \(cm)
    identical(toupper(cm$chamber %||% ""), "SENATE") &&
      grepl("Foreign Relations", cm$committeeName %||% "", ignore.case = TRUE)))
}

n_target <- 10
hearings <- list()
seen     <- character()
offset   <- "*"

while (length(hearings) < n_target) {
  page <- search_page(offset)
  if (length(page$results) == 0) break          # no more results: stop

  for (r in page$results) {
    id <- r$packageId
    if (is.null(id) || id %in% seen) next        # skip granules already seen
    seen <- c(seen, id)
    s <- get_summary(id)
    Sys.sleep(0.5)
    if (is_sfrc(s)) hearings[[id]] <- s
    if (length(hearings) == n_target) break
  }

  if (is.null(page$offsetMark) || identical(page$offsetMark, offset)) break
  offset <- page$offsetMark                      # send it back for the next page
}

message(length(hearings), " hearings found after checking ", length(seen), " packages")

B4. Download the PDFs and write the log

download_pdf <- function(id, url) {
  dest    <- file.path(pdf_dir, paste0(id, ".pdf"))
  started <- format(Sys.time(), "%Y-%m-%d %H:%M:%S %Z")

  res <- if (is.na(url)) {
    list(status = "no pdfLink", http = NA_integer_, error = NA_character_)
  } else {
    tryCatch({
      resp <- request(url) |>
        req_url_query(api_key = api_key) |>
        req_retry(max_tries = 3) |>
        req_perform(path = dest)
      list(status = "ok", http = resp_status(resp), error = NA_character_)
    }, error = \(e) list(status = "failed", http = NA_integer_,
                         error = conditionMessage(e)))
  }
  Sys.sleep(runif(1, 1, 3))  # polite pause, as in govtdata01.R

  tibble(
    packageId   = id,
    pdf_url     = url,                       # without the key
    file        = dest,
    status      = res$status,
    http_status = res$http,
    bytes       = if (res$status == "ok") file.size(dest) else NA_real_,
    error       = res$error,
    started     = started
  )
}

download_log <- map2_dfr(hearing_tbl$packageId, hearing_tbl$pdfLink, download_pdf) |>
  left_join(select(hearing_tbl, packageId, title, dateIssued, heldDates),
            by = "packageId")

write_csv(download_log, log_file)
